React Compiler

Phần lớn vấn đề hiệu năng RN đến từ re-render thừa. Memo bằng tay làm code khó đọc. React Compiler — công cụ của team React core — tự memoize lúc build.

1. React Compiler là gì?

Là công cụ phân tích cấu trúc component ở build time và tự áp dụng memoization để giảm re-render, thay cho React.memo, useMemo, useCallback viết tay.

Mốc thời gian

Khi sách viết (tháng 1/2025), compiler còn ở beta, Meta đã dùng ở production. Việc bạn dùng được hay không phụ thuộc code tuân thủ Rules of React đến đâu. Ở thời điểm bạn đọc, hãy kiểm tra bản ổn định mới nhất và tài liệu chính thức vì cách cài đặt đã được đơn giản hóa (xem mục bổ sung cuối chương).

2. Chuẩn bị & cài đặt

Bước 1 — ESLint plugin (nên làm ngay cả khi chưa dùng compiler)

Phát hiện vi phạm Rules of React và cảnh báo những thứ cản trở tối ưu — cải thiện chất lượng code và giúp chuyển đổi suôn sẻ.

> npm install -D eslint-plugin-react-compiler@beta

// eslint.config.js
import reactCompiler from 'eslint-plugin-react-compiler'
export default [{
  plugins: { 'react-compiler': reactCompiler },
  rules:   { 'react-compiler/react-compiler': 'error' },
}]

Bước 2 — Babel plugin

> npm install -D babel-plugin-react-compiler@beta

// babel.config.js
const ReactCompilerConfig = {
  target: '19'   // chọn theo phiên bản react của bạn
};
module.exports = function () {
  return { plugins: [['babel-plugin-react-compiler', ReactCompilerConfig]] };
};
  • Tương thích React 17+ nhưng hiệu quả phụ thuộc việc tuân thủ best practice. Không tối ưu class component, pattern cũ, hay component vi phạm Rules of React.
  • RN < 0.78 (đi kèm React 19): thêm react-compiler-runtime@beta và đặt target: '18'.

Áp dụng từng phần

Compiler có thể lỗi ở vài file. Cấu hình sources để bật dần, giảm rủi ro hồi quy:

const ReactCompilerConfig = {
  sources: (filename) => filename.indexOf('src/path/to/dir') !== -1,
};

3. Compiler biến code của bạn thành gì?

Trước:

export default function MyApp() {
  const [value, setValue] = useState('');
  return (
    <TextInput onChangeText={() => { setValue(value); }}>Hello World</TextInput>
  );
}

Sau (rút gọn):

import { c as _c } from 'react/compiler-runtime';
export default function MyApp() {
  const $ = _c(2);                       // bộ nhớ đệm 2 ô
  const [value, setValue] = useState('');
  let t0;
  if ($[0] !== value) {               // value đổi?
    t0 = <TextInput onChangeText={() => setValue(value)}>Hello World</TextInput>;
    $[0] = value;  $[1] = t0;       // lưu input và kết quả
  } else {
    t0 = $[1];                      // dùng lại kết quả cũ
  }
  return t0;
}

_c(n) là polyfill của useMemoCache(n) (React 19): tạo mảng n ô tồn tại qua các lần render, giống useRef:

function useMemoCache(n) {
  const ref = useRef(Array(n).fill(undefined));
  return ref.current;
}

Demo · Bộ nhớ đệm $ hoạt động ra sao

Bấm "Render lại" nhiều lần với cùng value: cache hit, không tạo mới. Đổi value → cache miss.

So sánh nông (shallow)

Compiler dùng so sánh nông, giống React.memo/useMemo. Cẩn thận với object/mảng làm props: nếu tham chiếu đổi, chúng bị coi là giá trị mới.

React Compiler Playground (trên trang React) cho bạn nhập code và xem compiler biến đổi, rất hợp để hiểu và gỡ hành vi bất ngờ.

4. Hỏi nhanh

Đã nên bỏ memo thủ công chưa?

Chưa vội. Compiler chưa thay thế hoàn toàn React.memo/useMemo/useCallback trong mọi trường hợp. Nếu code đang dựa nhiều vào chúng, hãy giữ cho tới khi compiler ổn định và React team xác nhận; linter sẽ chỉ ra cái nào thừa.

Cải thiện được bao nhiêu?

Thử nghiệm trên app Expensify: "Chat Finder Page Time to Interactive" cải thiện 4,3%. App đã tối ưu memo tay kỹ thì chỉ cải thiện nhẹ. Compiler hiệu quả nhất với app lớn, cây component sâu, nơi một cập nhật nhỏ gây re-render dây chuyền.

Làm sao biết đã tối ưu?

Mở React DevTools: component được compiler tối ưu có huy hiệu Memo ✨. Trong RN có thể cần thêm bước: RN dùng bản react-devtools riêng, hãy override trong package.json lên ≥ 6.0.1 (kiểm tra qua biểu tượng bánh răng của DevTools), nếu không huy hiệu Memo sẽ không hiện.

Bổ sung: React Compiler docs · Playground · Rules of React. Cách bật cho Expo/RN hiện đại có thể khác bản beta trong sách; xem tài liệu chính thức.
