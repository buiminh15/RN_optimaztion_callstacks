Tránh barrel exports

Barrel file gộp nhiều module vào một điểm export để import cho tiện. Nhưng sự tiện lợi này có giá: bundle phình to, khởi động chậm, và phụ thuộc vòng tròn.

1. Barrel file là gì?

// components/index.ts — một "index file"
export { Button } from './Button';
export { Card }   from './Card';
export { Modal }  from './Modal';

// nơi dùng
import { Button, Card, Modal, Sidebar } from './components';

2. Ba vấn đề

Kích thước

Bundle size overhead

Metro đưa mọi module trong barrel vào bundle dù bạn chỉ dùng một. Import mỗi Button vẫn kéo theo Card, Modal…

Thời gian chạy

Runtime overhead

Mọi module trong barrel phải được evaluate trước khi trả về module cần → xử lý thừa → ảnh hưởng TTI.

Phát triển

Circular dependency

Barrel dễ tạo phụ thuộc vòng. Hệ quả: phá HMR, buộc reload toàn bộ mỗi khi module trong vòng đổi. Metro cảnh báo khi phát hiện.

Demo · Bundle chứa gì?

Tick các component bạn thực sự dùng, rồi so sánh hai cách import. (Kích thước là số minh họa.)

Barrelimport { … } from './components'
Import trực tiếpimport X from './components/X'

3. Giải pháp: đừng dùng barrel import

// ❌ import từ barrel
import { Button, Card, Modal, Sidebar } from './components';

// ✅ import từ từng file
import Button from './components/Button';
import Card   from './components/Card';
import Modal  from './components/Modal';

Để giữ kỷ luật này cả dự án, thêm ESLint plugin: eslint-plugin-no-barrel-imports.

Một ngoại lệ hữu ích

Vài thư viện (ví dụ React Native Paper) cung cấp sẵn Babel plugin loại bỏ import không dùng, nên bạn không phải lo.

4. Xử lý tự động (nếu không muốn sửa tay)

Cách trên không "đẹp" lắm. Có công cụ làm tự động:

  • Expo SDK 52 thêm hỗ trợ thử nghiệm tree shaking, tự tối ưu barrel imports — chỉ module thực sự dùng mới vào bundle.
  • metro-serializer-esbuild (rnx-kit): cho ESBuild — cũng hỗ trợ tree shaking — tiếp quản việc bundling của Metro.
  • Webpack/Rspack: tree shaking nâng cao, loại export không dùng khỏi barrel.

(Xem thêm Chương 23 về tree shaking.)

5. Ví dụ thực tế: date-fns

Thư viện xử lý ngày giờ nổi tiếng, được thiết kế để hỗ trợ import submodule:

// ❌ nhập cả thư viện
import { format, addDays, isToday } from 'date-fns';

// ✅ chỉ lấy phần cần
import format  from 'date-fns/format';
import addDays from 'date-fns/addDays';
import isToday from 'date-fns/isToday';
Luôn đo

Xác nhận tác động lên JS bundle cuối cùng bằng các công cụ ở Chương 19. Lưu ý các phiên bản mới của date-fns (v3+) có thể đã khuyến nghị cú pháp import khác — kiểm tra tài liệu phiên bản bạn dùng.
